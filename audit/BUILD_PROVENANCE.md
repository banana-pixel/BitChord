## Security changes this branch makes (see FINDINGS.md)
1. Gradle wrapper files (`gradlew`, `gradlew.bat`, `gradle-wrapper.jar`, `gradle-wrapper.properties`) replaced with the exact set generated by the checksum-verified Gradle 8.11.1 distribution, and `distributionSha256Sum=f397b287023acdba1e9f6fc5ea72d22dd63669d59ed4a289a29b1a76eee151c6` added — future wrapper bootstraps verify the zip.
2. jsoup `1.22.2` → `1.23.2` (OSV HIGH+MOD URLs in DEPENDENCY_INVENTORY.md).
3. TV auth server: pairing code plus a per-session `HttpOnly` cookie; every `/api/*` and `/remote` call is checked per request, `Access-Control-Allow-Origin: *` removed, per-IP miss throttling.
4. Updater requires a resolved SHA-256 from the release's `BitChord-SHA256SUMS.txt` for every in-app install, with no date/version exception; a missing or untrustworthy digest withholds the download and the UI falls back to the releases page. android.yml generates that manifest.
5. Module-call arguments are escaped by `jsStringLiteral` before they are spliced into QuickJS source.
6. TV remote page builds result rows with `createElement`/`textContent` instead of `innerHTML`.
